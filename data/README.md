# Dataset

This directory stores dataset schemas, anonymised metadata, and documentation only.

## Do not commit

- raw Building Consent drawings
- project addresses
- purchase orders
- invoices
- supplier names or account details
- personally identifiable information
- confidential commercial pricing records

Raw project material should remain outside the public repository.

## Research record

Each usable project should eventually have an anonymised record containing:

- anonymous project ID
- plan availability
- structural-plan availability
- project/build date or cost date
- floor area and selected structured features
- foundation/concrete historical target cost
- framing historical target cost
- roofing historical target cost
- target-quality status
- inclusion/exclusion reason
- train/validation/test split

Missing target values must remain missing rather than being converted to zero.
